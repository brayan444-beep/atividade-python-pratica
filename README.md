# Projeto: Filtragem de Notas de Alunos com Python

Este repositório contém um script desenvolvido para a disciplina de Banco de Dados para demonstrar a filtragem de notas escolares.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python 3.x
* **Conceitos Praticados:** Estruturas de dados (Dicionários e Listas), loops (for) e condicionais (if/else).

## 💻 Como Executar o Script
1. Certifique-se de ter o Python instalado em seu computador.
2. Baixe ou clone este repositório.
3. No terminal ou prompt de comando, execute o arquivo:
```bash
python script.py
```
